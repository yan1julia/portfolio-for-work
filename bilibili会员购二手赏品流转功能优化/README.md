### bilibili会员购二手赏品流转功能优化

本项目以B站会员购为场景，针对扭蛋、一番赏等二次元周边的重复款及闲置流转问题，设计以**仓内二手交换**为核心的产品优化方案。用户可将商品暂存或核验入仓，通过IP专区发布换赏需求、比较多方提案并协商补差价，由平台完成仓内权益转移，减少重复寄送成本。在此基础上，进一步探索**平台回购、Token积分兑换及再次扭蛋机制**，让闲置赏品重新参与流转；同时结合仓储服务、交易收费与IP同好互动，探讨平台商业化及二次元收藏社区的发展可能。
